# BlueShark add-on

Serves the BlueShark web workbench through Home Assistant Ingress as a
**BlueShark** sidebar panel. Use it to import btsnoop / JSON / CSV captures
and review them from a desktop. It requests no Bluetooth, DBus, device or
host-network privileges; the `blueshark` custom integration performs the
explicitly enabled, device-tested GATT writes. The Android app is the
first-class capture tool.
